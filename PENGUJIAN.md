# Dokumentasi Pengujian Aplikasi Data Buku

## 1. Tujuan Pengujian
Pengujian dilakukan untuk memastikan fitur CRUD pada aplikasi Data Buku berjalan sesuai fungsinya.

## 2. Skenario Pengujian

| No. | Fitur | Hasil yang Diharapkan |
|---|---|---|
| 1 | Read | Data buku ditampilkan dalam tabel. |
| 2 | Create | Data buku baru tersimpan dan muncul di tabel. |
| 3 | Update | Perubahan data buku tersimpan dan ditampilkan. |
| 4 | Delete | Data buku yang dipilih terhapus dari tabel. |
| 5 | Validasi | Input yang tidak sesuai ditolak oleh aplikasi. |

## 3. Teknologi Pengujian
Pengujian dilakukan menggunakan aplikasi pada server lokal Laragon, browser, PHP Native, dan database MySQL/MariaDB.

## 4. Kesimpulan
Pengujian digunakan untuk memeriksa fungsi utama aplikasi Data Buku. Hasil akhir setiap skenario dicatat berdasarkan pengujian langsung pada aplikasi.
